**Hear your Windows PC through the hearing aids or headphones connected to your iPhone.**
**把 Windows 电脑的声音，通过 iPhone 送进你的助听器或耳机。**

### Downloads / 下载

| File / 文件 | For / 适用于 |
|---|---|
| `SoundBridge-Windows-x64.exe` | Most Windows 10/11 PCs. Nothing else to install.<br>绝大多数 Windows 电脑，不用额外装任何东西 |
| `SoundBridge-Windows-ARM64.exe` | Windows on ARM (Snapdragon laptops)<br>ARM 芯片的 Windows 电脑 |
| `SoundBridge-Windows-x64-lite.exe` | Small, needs the .NET 10 Desktop Runtime<br>体积小，需要先装 .NET 10 桌面运行时 |
| `SoundBridge-iOS-unsigned.ipa` | iPhone / iPad, iOS 15+. Sideload with AltStore, Sideloadly or your own signing tool.<br>iOS 15 及以上，需要用 AltStore、Sideloadly 或其他签名工具安装 |

See the [README](https://github.com/Mirazia/SoundBridge#readme) for setup and troubleshooting. / 安装和常见问题见 [README](https://github.com/Mirazia/SoundBridge#readme)。

### What's in this version / 本版内容

- Windows app with a window and tray icon, plus a live level meter. / 电脑端是窗口加托盘程序，带实时音量条。
- New iPhone app: one big button, lock-screen and Dynamic Island controls, a 3-step guide on first launch. / iPhone 端新界面：一个大按钮、锁屏和灵动岛控制、首次打开有三步引导。
- Automatic discovery, with a local-network scan as a fallback for routers or hotspots that block multicast. / 自动发现电脑；路由器或随身 Wi-Fi 拦截组播时，会改为扫描局域网。
- Streams at your output's sample rate (16 kHz for hearing aids); delay adjusts automatically. / 按输出设备的采样率传输（助听器为 16 kHz），延迟自动调节。
- Reconnects automatically when the stream stalls. / 断流后自动重连。
- 10 languages. / 支持 10 种语言。
